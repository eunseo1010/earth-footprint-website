# 질문 답변 저장 전용 수정본

마지막 질문에 답변하면 결과 화면으로 이동하지 않고 Question 07에 그대로 머무릅니다. 답변 확인 목록과 결과 화면은 제거했습니다. 저장 완료 문구만 표시합니다.

저장 위치: 현재 브라우저 탭의 sessionStorage, 키 earth-question-pages-v1. 새로고침 후 복원 가능하나 장기/영구 저장이 아닙니다. 탭 종료 시 일반적으로 삭제됩니다. 저장이 차단되면 실패 안내를 표시합니다. 서버/API로 전송하지 않습니다. 탄소 계산 결과가 아닌 사용자가 선택한 답변 7개를 저장합니다.

실행: index.html을 직접 열거나, 이 폴더에서 python app.py 실행 후 http://127.0.0.1:8000 접속.

이전 질문 버튼으로 답변 수정 가능. 7번 답변 수정 시 다시 저장합니다. 배경·식물 장식·7개 질문·29개 선택지·기존 버튼 디자인은 유지했습니다.

app.py는 기존 정적 파일 제공 및 검증 API를 유지하나 화면에서는 검증 API를 호출하지 않습니다.

## 질문별 원형 아이콘
Q1 교통수단 / Q2 배달음식 / Q3 음료 / Q4 의류 / Q5 전자기기 / Q6 에어컨 / Q7 비닐봉지. 질문 카드 상단의 기존 원에 표시되며 질문 이동 시 변경됩니다. 제공된 투명 이미지는 투명 여백만 정리하고 비율을 유지해 원 안에 배치했습니다. assets/icons의 해당 PNG를 교체하여 변경할 수 있습니다.
